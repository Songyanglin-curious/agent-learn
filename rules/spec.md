# 学习工作区与资料规格

本规则定义学习资料的职责。学习者数据存入用户指定的工作区，不写进插件安装目录或用户规则目录。项目自身的开发 Docs 也不自动成为学习档案。

## 工作区启用

DSH 会话的 cwd 应指向学习工作区根目录。自动检查只认当前 cwd 下的 `.agent-learn.json` 和 `index.md`，不向父目录查找、不扫描其他领域。标记内容为：

```json
{
  "version": 1,
  "enabled": true
}
```

标记只表达本工作区启用状态，不是学习数据库。设为 false 可停用自动检查；普通教学和显式规则入口仍可使用。版本不符、标记损坏或缺少根索引时不会自动修复和初始化。

## 最小组织

根 `index.md` 只索引直接子级领域，每个条目说明内容与何时进入。一个领域有自己的 `index.md`、`学习计划.md` 和 `学习进度.md`。已有 `plan.md`、`progress.md` 等有效资料继续使用，从索引明确位置，不为统一名称迁移或制造副本。上层或工作区已有命名规范优先。

知识笔记、案例、评测和可视化按需建文件或目录。新增内容目录同时创建其 `index.md`，每级仅索引直接子级，不预建空目录。

| 资料 | 主要内容 | 更新条件 |
| --- | --- | --- |
| 学习计划 | 动机、能力目标、范围、必要依赖、深度和大致路线 | 用户确定或调整长期方向；不随每轮教学变动 |
| 学习进度 | 当前问题、活跃主线与支线、证据、缺口、接续位置 | 出现实质变化或当前快照失准 |
| 知识笔记 | 可独立查阅的解释、机制、边界及来源 | 教学单元收束时更新已有主题，缺失则新建简短笔记；零散答疑不必另建 |
| 案例与评测 | 有复用价值的场景、表现证据、判断与补强建议 | 已完成且有阶段意义；计划中的题目不写作评测成果 |

## 学习进度的必要表达

以最小文字或表格记录，内容不足时不强填模板：

- 主线：正在解决的实际问题、相关目标，以及当前接续位置。
- 当前焦点：本轮实际围绕什么展开，可与主线不同。
- 活跃支线：每条说明问题、关联主线或前置支线、状态（处理中或暂挂）、返回位置、尚缺什么。仅出现真实需要接续的问题时新增，普通一句解释不建支线。
- 理解证据：区分 AI 已讲、用户自述、提示后分析与独立应用；附关键依据和未确认处。
- 阶段判断与下一动作：需要时简短说明当前是补充、检验、沉淀、接续还是暂停，以及理由。优先保留一个具体动作，允许为空或标明等待用户回应。

多条支线允许并存，不强制按栈返回。已经够用的支线从活跃列表移除；把仍有价值的认识、证据或遗留缺口放到本文件相应位置，或链接到主题笔记。不另建无界增长的已完成清单。

接续线索须包含当前问题、已用模型和下一缺口，不能只写阶段编号、术语或一道待答题。根索引不再维护一份相同进度，跨领域恢复时由用户意图和领域索引定位。

## 内容质量

各资料有一个主要维护位置，不复制多份正文。区分事实、教学简化、学习者表现和 AI 推断；来源、适用条件、单位与不确定点应清楚。局部更新关联索引，不借学习维护重组整个工作区。
