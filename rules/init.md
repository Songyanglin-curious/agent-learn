# 学习工作区初始化

仅用户明确要求初始化、建立持续学习或持续跟踪时执行。先按需读取同目录的 [原则](principles.md) 和 [工作区规格](spec.md)。仅询问知识或比较规划不自动初始化。

## 确认与复用

1. 从当前对话取得学习目的、范围、基础、目标深度与工作区；已有信息不反复询问。只有缺少关键条件才问一个最重要的问题。
2. 用户指定工作区优先；路径不明且需要落盘时询问一次，不猜测，不把插件源码目录当成学习目录。
3. 当前会话 cwd 不等于指定工作区时说明：自动 Hook 只覆盖指定目录作为 cwd 的聊天；保存学习资料不等于已绑定当前会话，不自行更改其他聊天配置。
4. 检查工作区已有指令、索引、相关领域及 `.agent-learn.json`；按索引读取必要原文，保留现有资料。已有可用入口时增量接入，不重建。
5. 已有启用标记损坏、版本不符或明确停用时说明问题，不静默覆盖；停用状态只有用户要求启用时才改。保留已有未知字段。

## 最小创建

围绕已确认的真实目标形成精简路线：希望解决什么任务，近期先建立哪个模型，依赖哪些基础，什么程度够用。当前单元具体，远期只保留方向；不生成大量课时或题库。

在用户已要求建立持续学习的范围内直接落盘，不再请求逐项批准：

- 根 `index.md`：已有领域的入口、内容和使用场景。
- 当前领域 `index.md`：计划、进度及已有资料的直接子级导航。
- `学习计划.md` 与 `学习进度.md`：职责按 spec；原有等效文件保留。
- 如工作区需要 Agent 长期使用，增补已有 `AGENTS.md` 的学习导航，或创建最小入口：从根索引恢复当前领域，学习时用 agent_learn_rules 读取规则。不要复制整套规则。

状态以当前真实对话为依据，未知留待确认；不把计划当成果，不把 AI 的讲解写成用户已经掌握。

必要文件可读、导航有效后，最后创建缺失的 `.agent-learn.json`，内容按 spec。启用表示允许在该学习工作区内依据实质变化维护进度与有价值的成果，不表示允许改变长期目标、迁移或删除重要资料。

## 回读与结束

重新读取本次创建或修改的文件，检查索引可达、目标准确、状态有依据、未覆盖已有资料。简短说明位置、切入点及实际启用范围。初始化轮次不再重复结束维护，不自动安装插件、提交 Git 或展开完整课程。
