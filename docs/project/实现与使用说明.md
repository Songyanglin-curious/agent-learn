# 实现与使用说明

## 运行组成

本项目只提供 DSH Bundle，包名 dsh-agent-learn，插件标识 agent-learn。cordis.patch.yml 将插件挂入宿主；必需注入 agents、tools、systemPrompt。文件读写使用原 Agent 的现有工具，插件没有独立模型、数据库或文件维护后台。

| 位置 | 职责 |
| --- | --- |
| src/index.mjs | 注册教学路由、agent_learn_rules 工具和 agent/turn-stopping 监听器 |
| src/workspace.mjs | 验证当前 cwd 的启用标记和学习根索引 |
| src/rules.mjs | 包内默认规则定位、显式自定义补齐、完整依赖回退与指令生成 |
| rules/ | principles、spec、init、teaching、maintain 五份默认规则的唯一源 |
| scripts/build.mjs | 将运行代码与规则复制到 lib/defaults，构建产物独立于仓库外文件 |
| scripts/pack.mjs | 使用 npm 标准打包链生成 TGZ 与 SHA-256 清单 |
| tests/ | 公开事件接口、规则文件保护及真实 Cordis/DSH 服务测试 |

普通教学通过简短系统提示路由到 teaching；此路由在插件加载后全局可见，但明确排除普通一次性问答和非学习任务，不全局注入完整规则。完整规则由原 Agent 按需读取。

## 工作区边界

只有当前会话 header.cwd 是绝对路径，并且该目录下存在有效 `.agent-learn.json`（version=1、enabled=true）和 index.md 文件时才自动检查。不向父目录搜索，不由配置强绑所有聊天，不在 Hook 中初始化。工作区标记每轮重新读取，停用下轮生效。

标记仅用于显式启用，详细学习数据采用 Markdown 当前快照；不把标记扩成学习数据库。根索引导航领域，领域内保存计划、进度和按需产生的笔记。已有 plan/progress 等文件可继续使用；具体规则由包内 spec 定义。

## 规则工具

- init：供用户明确要求建立持续学习时读取初始化规则，工具不直接创建学习工作区。
- teaching：读取教学、支线管理和阶段选择规则，不抑制本轮自动维护。
- maintain：显式进行状态和成果补漏。
- info：返回当前规则目录和三类操作规则的实际路径，不抑制本轮自动维护。

规则目录优先级：插件 rulesDir、AGENT_LEARN_RULES_DIR、DSH 安装包内 defaults。默认只读包内规则，不创建用户根目录副本，升级立即使用新版默认规则。仅显式自定义目录会补齐缺失的五份规则，不覆盖用户文件；自定义依赖不可读时整套回退包内 defaults。旧版 ~/.agent-learn/dsh 不再自动读取、迁移或删除。

用户规则为自定义版本，不随源码发布自动升级。工具会返回实际 cwd（可取得时）和规则路径；规则路径不等于学习数据目录。

## 轮次结束检查

使用 DSH 的 agent/turn-stopping serial 事件。WeakMap 按 Agent 和 turn 去重，先标记再检查工作区，异常不会在同轮无限重试。跳过 origin=subagent 或 delegationDepth>0，普通带 parentSessionId 的 fork 不误排除。

有效工作区内用 agent.steer(createUserMessage(...)) 投递一次补漏指令，消息来源为插件自有的 kind=agent-learn、form=instructions。它让同一个 Agent 在当前上下文处理必要记录，不创建第二个 Agent。

显式调用 init 或 maintain 时按宿主 turnBoundaryOf 的 lastTurn 抑制同轮提醒；读取 teaching 或 info 不抑制。enabled=false 仅关闭自动 Hook，保留工具和轻量路由。

取消、卸载或异常不继续投递。监听器和工具由 Cordis 生命周期托管；没有自建定时器和后台异步任务。与其他 Hook 共存时各自去重，可能收到多个插件的提醒；不接管其他插件或跨插件共用“已维护”标记。

## 使用与效果边界

安装、启用和规则编辑步骤见仓库根 README.md，独立 TGZ 同时携带该说明。0.1.2 的教学与轮末指令要求在单元收束并转向下一单元时维护主题笔记；本地 Hook 检查只能验证指令投递，实际落盘仍要在真实学习对话中验收。目标宿主为 DSH 0.2.2-rc.1，Cordis 4.1.0；依赖升级后须重新验证，不绕过版本门禁。

插件不直接修改学习档案。学习记录、能力判断和成果沉淀依赖原 Agent 遵循规则并实际执行文件操作；本地 Hook 和消息协议测试通过，不等于真实教学效果已经验证。
