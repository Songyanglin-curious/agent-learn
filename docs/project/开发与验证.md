## 可重复命令

在项目根目录执行 npm test、npm run pack、npm run verify:package。构建源为 src 和 rules；lib、defaults、dist 为可再生成产物，均忽略入库。npm pack 的 prepack 会先构建，npm run pack 同时写出 dist/SHA256SUMS.txt。

verify:package 使用 PATH 上的 tar，也支持 AGENT_LEARN_TAR 指定绝对路径。测试支持 AGENT_LEARN_ENTRY 指定独立包的真实入口；设置 AGENT_DOCS_ENTRY 为 agent-docs 的 DSH lib/index.mjs 可额外验证两个插件共存。

## 未验证与实际边界

本次没有修改日常 web/code Profile、安装缓存或已有用户规则，没有在真实学习工作区创建启用标记，也未自动覆盖 learning-coach 原型。

未启动在线模型学习会话，未验证真实 AgentLoop 的同轮模型续接，也未让模型实际生成学习档案。因此主线/支线识别、教学节奏、阶段判断、成果沉淀时机与跨会话恢复仍需实际使用验收。规则文本中的要求是指导，不是已发生的效果。

验收场景：主线追问一条支线，支线够用后从活跃列表移除但保留认识；用户只认可一个结论时不强行跳课；用户明确继续时自然接续；暂停时保存位置；普通重复解释不写流水账。位置与记录仅限用户授权的学习工作区。
