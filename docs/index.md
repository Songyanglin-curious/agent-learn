# agent-learn 文档

agent-learn 面向 AI 辅助学习，以轻量 Hook 与 Markdown 规则提供学习接续、成果沉淀和节奏协调。当前实现 DSH 插件 0.1.0，真实学习对话效果尚待验收。

- [项目现状](project/index.md)：说明仓库实际内容与实现边界；确认目前有哪些可用内容时阅读。
- [需求与设计](design/index.md)：保存学习外骨骼的定位、模块职责与设计依据；讨论或实现学习闭环时阅读。
- [待处理事项](pending/index.md)：管理仍需执行的工作；检查已确定的后续行动时阅读。
- [验证材料](evidence/index.md)：说明临时验证材料的存放与入库边界；开展验证时阅读。
- [项目规则](rules/index.md)：保存持续适用的开发约定；编写或修改代码时阅读。
- [知识与经验](knowledge/index.md)：保存值得复用的原理和经验；查阅工程方法时进入。
- [暂存资料](inbox/index.md)：容纳暂未明确归属的资料；接收未分类材料时进入。
