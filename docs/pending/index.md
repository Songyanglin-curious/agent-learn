# 待处理事项

当前 DSH 专题生命周期待真实对话验收：

- 规划迁移：选择一个范例里没有出现的专题，只给学习目标和已有基础。检查计划能解释各部分关系及顺序理由，后续阶段确实用同一核心认识获得新的解释或应用能力，相关内容按学习目标组织。另检查计划存在可直接开讲的问题、阶段成果与专题综合安排，并保存为独立文件。
- 轻量专题：建立简短、独立且可导航的专题计划；用一批相关内容支撑一个完整判断，追问后能下钻并回到原问题，不为临时分支建文件。
- 复杂专题：先给脉络与阶段路线，发现结构问题时修订原计划，阶段综合与专题总综合各自重建结构。暂挂或跳过一段、完成后面的阶段再重排路线，新会话仍能找到各阶段的实际状态和接续点。
- 反向检查：已启用工作区内，普通答疑不调用 teaching，Hook 直接放行。专题教学收到提醒后，无遗漏时直接结束，有遗漏时只补写已经发生的变化。

验收须在用户选择的实际学习工作区与 Profile 中进行，本次不更改日常安装配置。不把事件测试对象或规则文本检查当成真实教学验收。
