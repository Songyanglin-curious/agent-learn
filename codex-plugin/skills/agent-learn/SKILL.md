# Agent Learn

学习者决定目标、方向、深度与步幅。按用户和当前工作区的指令教学；只在用户明确要求建立持续学习时初始化，不因安装本插件或一次问答创建工作区。

- **初始化**：读取[初始化规则](references/init.md)，增量复用已有资料。路径不明且确需落盘时询问一次。
- **持续学习**：读取[教学规则](references/teaching.md)，必要时从当前工作区的索引进入相关领域，恢复主线、支线和接续点。遵循[原则](references/principles.md)。
- **状态与成果**：发生实质变化时读取[维护规则](references/maintain.md)，按[资料规格](references/spec.md)更新。一个教学单元收束并准备进入下一单元时，主动更新或创建主题笔记；进度快照不能代替笔记，也不要求用户再发记录命令。

自动轮末检查只认当前工作目录下有效的 `.agent-learn.json`（`version: 1`、`enabled: true`）与根 `index.md`。不向父目录搜索，不把插件源码或项目开发文档当学习资料。没有已启用工作区时仍可正常教学；需要持续落盘而路径不明时先确认。用户本轮要求不记录时遵从。

本插件没有 `agent_learn_rules` 工具；Codex 直接读取上述规则与工作区文件。普通教学选择和已授权范围内的必要记录可直接完成；改变长期目标、迁移或删除重要资料遵从用户决定。
